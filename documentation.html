E-Commerce Frontend Template Documentation

Thank you for purchasing our template. If you have any questions, please contact support.

1. Folder Structure

Extract the ZIP package. You will find the following clean directory structure:

├── index.html                # Main Homepage
├── products.html             # Products Catalog / Grid Page
├── documentation.html        # This guide file
├── css/
│ ├── main.css              # Core layout and base settings
│ ├── components.css        # Navbar, Footer, Buttons, and Cards
│ └── responsive.css        # Media queries for mobile/tablet optimization
├── js/
│ ├── products.js           # Script handling dynamic product grid rendering
│ └── main.js               # UI interactions (slider, menus, countdowns)
└── assets/
└── images/               # Commercially licensed placeholder graphics

2. Managing and Adding Products

Products are generated dynamically using JavaScript for better optimization. To add, edit, or remove products, open js/products.js and update the product array structure:

// Example Product Object in js/products.js
{
    id: 1,
    title: "High-end Custom PC",
    price: 500,
    oldPrice: 600,
    rating: 4.9,
    image: "assets/images/product-pc.jpg"
}

3. Customizing Colors & Fonts

Global branding elements like primary theme colors are managed inside css/main.css. Simply change the CSS root variables to match your brand style:

:root {
    --primary-color: #db4444;    /* Main action color */
    --text-dark: #111111;        /* Headers and title text */
    --bg-light: #f9f9f9;         /* Section backgrounds */
}
Note on Images: All images included in this template are sourced from free stock repositories (Unsplash/Pexels) and are strictly for preview purposes. Remember to upload your compressed web-ready images under assets/images/.
